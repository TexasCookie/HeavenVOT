Настройки AetherVox

Два пайплайна: Live realtime для стримов и VOD prepare для обычных видео — плюс голоса, токены, сеть из РФ.

1. Провайдер Local / xAI

Local (по умолчанию): STT + MT + TTS через шлюз 127.0.0.1:8788 + LM Studio на :1234 — без облака и без цензуры. xAI: облачный Grok (ключ обязателен; облако может фильтровать контент).

Ключ xAI (только для режима xAI)

Создай ключ на console.x.ai.

2. Пайплайны перевода

Это то, ради чего обновлялся движок. Обычные видео больше не гоняются как live-стрим: готовится полный банк фраз (Yandex-style), и только потом идёт синхрон. Стримы — низкая задержка, clause MT, WebSocket.

LIVE realtime · стримы

Live realtime

  • STT WebSocket (~100 ms PCM frames)
  • Partial MT по clauses до конца фразы
  • TTS WS · цель 1.5–3s first-audio
  • SyncEngine + lag-shed + HealthMonitor
  • REST fallback если WS/auth падает
VOD prepare · обычные видео

VOD prepare

  • Скан аудиодорожки (ускоренный offline pass)
  • Параллельный STT → MT → TTS в банк cues
  • Прогресс в overlay / popup
  • Когда готово — озвучка по таймкодам (пауза до полного банка)
  • Не путать с live: realtime только для стримов

В popup и на плеере (кнопка AV) тот же переключатель Авто / Live / VOD и live-индикаторы: badge пайплайна, прогресс prepare, latency stages.

3. Языки и «живые» голоса

По умолчанию natural/live-голоса (Ara, Carina, Luna…). Если API не отдаёт такой голос — fallback на neural (Eve, Sal…).

4. Live-детали и MT

Эти флаги влияют в основном на Live-путь. VOD prepare всегда строит полный банк (параллельный fan-out).

5. Экономия токенов API (MT)

GlyphPack — пакует правила, глоссарий, историю и контекст в плотную PNG (image-токены). Живая фраза (SRC) остаётся текстом. При сбоях — fallback на Standard. Live по умолчанию — standard text (ниже RTT); Glyph полезен для толстых offline-глоссариев / max.

7. Глоссарий, исключения и keyterms

Keyterms — bias для STT. Глоссарий — принудительные пары. Исключения — слова, которые нельзя переводить (бренды, имена, код). Самообучение тоже пополняет эти списки.

8. Самообучение перевода

AetherVox запоминает термины и ошибочные переводы. Может авто-обновлять устаревшие субтитры/озвучку, пока смотришь.

9. Связь из РФ / прокси

По умолчанию — напрямую (системный VPN не трогаем). PAC расширения только для api.x.ai. Режим Авто меряет RTT: direct → HTTPS-relay → SOCKS/HTTP.

Streaming WebSocket: ephemeral client_secrets → Sec-WebSocket-Protocol, либо relay с _av_key. Relay нужен если сеть режет api.x.ai: node tools/xai-relay-local.mjs → http://127.0.0.1:8787/v1.

10. Надёжность

Почему это бьёт типичный Yandex / VOT-скрипт

  • Два пайплайна — Live для стримов, VOD prepare для обычных видео (не «один костыль на всё»).
  • Контекстный Grok — чинит ASR-омонимы по теме видео.
  • SyncEngine — adaptive offset, skip лагов, без вечного рассинхрона.
  • HealthMonitor — toast + notification + auto-recover.
  • Streaming path — WS STT + clause MT + TTS, цель 1.5–3s first-audio.
  • JP/KO/ZH/AR… — hard-pair промпты + keyterms + multilingual STT.
